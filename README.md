# Trading — расчёт прибыли акций (Android)

Нативный Android-проект на Kotlin без сторонних библиотек. Интерфейс на русском языке, тёмная тема, автоматический расчёт и локальная история сделок.

## Логика расчёта

- Объём покупки = цена покупки × количество.
- Объём продажи = цена продажи × количество.
- Прибыль до комиссий = объём продажи − объём покупки.
- Комиссия покупки = объём покупки × ставка комиссии покупки.
- Комиссия продажи = объём продажи × ставка комиссии продажи.
- Прибыль после комиссий = прибыль до комиссий − комиссия покупки − комиссия продажи.
- Налог = max(прибыль после комиссий, 0) × ставка налога.
- Чистая прибыль = прибыль после комиссий − налог.
- Цена безубыточности учитывает комиссии покупки и продажи: цена покупки × (1 + комиссия покупки) / (1 − комиссия продажи).

По умолчанию комиссии покупки и продажи — 0,3%, налог — 13%. Эти значения можно менять на экране. Налоговый расчёт ориентировочный и не заменяет расчёт налогового агента с учётом применимых правил и налоговой ситуации пользователя.

## Сборка APK в Android Studio

1. Установите Android Studio (актуальную стабильную версию) и Android SDK Platform 35.
2. Распакуйте архив проекта в отдельную папку.
3. В Android Studio выберите **Open** и укажите папку `StockTradingApp` (в ней находятся `settings.gradle.kts` и `build.gradle.kts`).
4. Дождитесь Gradle Sync. При первом запуске потребуется интернет для загрузки Gradle и Android Gradle Plugin.
5. Для установки на подключённый Android-телефон включите «Для разработчиков» → «Отладка по USB», подключите телефон и нажмите **Run**.
6. Чтобы собрать APK: **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
7. Готовый debug APK появится по пути `app/build/outputs/apk/debug/app-debug.apk`. В уведомлении Android Studio нажмите **locate** для открытия файла.

## Сборка из терминала

Из папки проекта выполните (если установлен Gradle и Android SDK):

```bash
gradle assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Данные и приватность

История хранится в SharedPreferences приложения на устройстве. Сетевые разрешения и передача данных не используются. При удалении приложения локальная история может быть удалена системой. Функция экспорта/резервного копирования в этой версии не включена.

## Получение APK без установки Android Studio (через GitHub Actions)

В проект добавлен workflow `.github/workflows/build-apk.yml`, который собирает APK в облаке GitHub Actions.

1. Создайте репозиторий на GitHub и загрузите туда содержимое папки `StockTradingApp`.
2. Откройте вкладку **Actions** и запустите workflow **Build Android APK** (кнопка **Run workflow**), либо дождитесь автоматической сборки после push.
3. Откройте завершившийся запуск workflow, найдите раздел **Artifacts** и скачайте `Trading-debug-APK`.
4. Распакуйте скачанный архив на телефоне или компьютере. Файл `app-debug.apk` можно перенести на Android-телефон и установить.

Это debug APK для личной установки и тестирования, не подписанный ключом публикации в Google Play.
